🚀 Multi-Session Orchestrator

Parallel Claude Code Development with Real-Time Coordination

What Is It?

The Multi-Session Orchestrator enables multiple Claude Code AI sessions to work on the same project in parallel while coordinating efficiently.

⚡ 3x Faster
Run 3 tasks in parallel instead of serial
🔄 Real-Time Sync
Sessions see each other's changes instantly
📋 Task Queue
Automatic task distribution
💬 Inter-Communication
Sessions alert and coordinate

Quick Start

1️⃣ Install Dependencies

pip install -r requirements_orchestrator.txt

2️⃣ Start Orchestrator Server

python orchestrator_server.py

3️⃣ Run Example Sessions

python example_sessions.py

4️⃣ Monitor Progress

curl http://localhost:8000/status

Files You Have

📦 Core Components

  • orchestrator_server.py - Central coordination server (WebSocket + REST API)
  • orchestrator_client.py - Client library for Claude sessions
  • example_sessions.py - 3 parallel sessions example (Backend, Frontend, QA)
  • requirements_orchestrator.txt - Python dependencies
  • MULTI_SESSION_GUIDE.md - Detailed documentation

How It Works

1
Server Starts
Orchestrator listens on ws://localhost:8000
2
Sessions Connect
Backend, Frontend, and QA sessions establish WebSocket connections
3
Tasks Distributed
Each session requests tasks based on priority
4
Work in Parallel
All sessions work simultaneously on different tasks
5
Real-Time Communication
Sessions notify each other of progress and file changes
6
Done!
Project complete 3x faster!

Example: Performance Comparison

Without Orchestrator (Serial)

Session A: Task 1 (10 min) Session B: Waiting... (10 min) Session C: Waiting... (10 min) Total: 30 minutes

With Orchestrator (Parallel)

Session A: Task 1 (10 min) ✓ Session B: Task 2 (10 min) ✓ Session C: Task 3 (10 min) ✓ Total: 10 minutes (3x faster!)

API Endpoints

WebSocket

ws://localhost:8000/ws/{session_name}

REST (HTTP)

GET  /status              - Orchestrator status
GET  /health              - Health check
POST /tasks               - Create new task
GET  /tasks               - List all tasks
GET  /tasks?status=X      - Filter by status

  • ✅ File Change Notifications - All sessions see file modifications
  • ✅ Session Status - Know what each session is doing
  • ✅ Message Broadcasting - Coordinate between sessions
  • ✅ Task Dependencies - Chain tasks in correct order
  • ✅ Block Detection - Handle waiting tasks
  • ✅ SQLite Persistence - Task history and logs
